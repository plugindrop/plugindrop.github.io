## 22 Soundtoys Effects Plugins Under One iLok License
<!-- role:product -->

Soundtoys, the maker, describes 5.5 as "The Ultimate Plugin Collection," a single installer covering 22 named effects: Crystallizer, Decapitator, EchoBoy, Effect Rack, Little AlterBoy, EchoBoy Jr., LittlePlate, PrimalTap, Devil-Loc Deluxe, Radiator, MicroShift, Tremolator, Sie-Q, FilterFreak, PhaseMistress, PanMan, Little MicroShift, Little PrimalTap, Little Radiator, Devil-Loc, SuperPlate, and SpaceBlender. Rather than selling each plugin separately, the collection ties them to one license.

Setup runs through a Soundtoys account rather than a generic installer: a buyer creates an account at the Soundtoys dealer-purchases page, verifies the address by email, signs in, then enters the 10-digit code from the Plugin Boutique order under "Dealer Purchases." Once submitted, the license appears on the My Products page alongside the installers and activation code. Soundtoys lists Decapitator as the example plugin walked through in that registration flow. Using any plugin in the bundle, trial or purchased, requires an iLok account. A short promotional video, "Introducing Soundtoys 5.5," accompanies the release to walk through the same collection.

## FabFilter's Ducking and Thickness Controls Against Soundtoys's Named Effects
<!-- role:peers -->

FabFilter's Total Bundle takes a different route to the same shelf of mix effects: its listed updates add a ducking control for separating dry and wet signal paths and a thickness control for adjusting program-dependent density and saturation, both built as parameters inside FabFilter's own plugins. Soundtoys 5.5 instead spreads that kind of signal shaping across 22 separately named tools — Decapitator for one behavior, Radiator or SuperPlate for others — so a producer picks a dedicated plugin per task rather than a control knob inside a shared one. Full details on FabFilter's additions are listed on the [FabFilter Total Bundle product page](https://www.pluginboutique.com/product/1-Instruments/57-Complete-Collection/16649-FabFilter-Total-Bundle).
