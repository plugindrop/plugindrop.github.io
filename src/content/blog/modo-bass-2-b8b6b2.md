## What Is MODO BASS 2?

MODO BASS 2 is a virtual bass instrument plugin from IK Multimedia built on component modeling technology rather than recorded samples. Instead of triggering pre-recorded notes, it simulates the physical behavior of a bass — body, strings, pickups, and playing technique — in real time. This is the second generation of IK's MODO BASS line, which also includes MODO DRUM using the same modeling approach.

## Key Features

- **Physical modeling engine** — generates tone from a simulated instrument rather than samples, so parameters like string tension and pickup position respond dynamically instead of triggering fixed recordings.
- **Adjustable instrument build** — lets you change bass type, body, neck, and pickup configuration to shape tone without switching to a different sample set.
- **Playing technique control** — supports different playing styles (such as fingers, pick, and slap) with adjustable articulation parameters.
- **Built-in amps and effects** — includes onboard amp and effect processing so the signal chain can be shaped inside the plugin.
- **MIDI-driven workflow** — designed to work from MIDI input, useful for programming bass parts without recording a live instrument.
