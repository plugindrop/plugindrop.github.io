## What Is Phase Plant?

Phase Plant is a semi-modular synthesizer by Kilohearts, a Swedish audio software company. It combines multiple synthesis types — wavetable, analog-modeled, sample-based, and more — within a single visual signal-flow environment. The plugin sits at the center of Kilohearts' broader "Snapins" ecosystem, where effects processors are interchangeable across the entire product lineup. It runs on both Windows and macOS — check the product page for current system requirements.

## Key Features

- **Semi-modular synthesis architecture** — Combines wavetable, granular, and analog-modeled oscillators without requiring patch cables; signal flow is handled visually.
- **Snapins integration** — Effects slots inside Phase Plant accept Kilohearts Snapins, so any compatible Snapins you already own work natively inside the synth.
- **Drag-and-drop modulation** — LFOs, envelopes, and macros connect to nearly any parameter via a visual, node-based modulation system.
- **Content Banks** — Officially curated preset packs that expand the factory library with genre-targeted sounds and patches.
- **MPE support** — Compatible with MIDI Polyphonic Expression controllers for expressive, per-note performance.
- **Flexible voice architecture** — Includes unison stacking and polyphony controls for wide, layered sound design.
