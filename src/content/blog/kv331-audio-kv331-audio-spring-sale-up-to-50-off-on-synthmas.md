## What Is KV331 Audio Synthmaster?

KV331 Audio is the developer behind the Synthmaster series — a family of semi-modular software synthesizers built to handle multiple synthesis methods within a single instrument. The flagship **Synthmaster 2** covers deep sound design territory, while **SynthMaster One** offers a streamlined interface for producers who want power without the complexity. Both run as VST/VST3/AU/AAX plugins on Windows and macOS. The ecosystem extends into a catalog of expansion packs spanning cinematic, EDM, and beyond.

---

## Key Features

- **Multi-engine synthesis** — Synthmaster 2 combines VA, wavetable, additive, PCM, and other modes in one plugin, reducing the need to juggle separate instruments.
- **Semi-modular architecture** — A flexible modulation matrix allows free parameter routing for complex, layered patches without hardware patching.
- **Layered oscillators** — Independent oscillator layers can each run a different synthesis type, enabling hybrid sounds in a single patch.
- **Large factory preset library** — Both synths ship with extensive included presets; expansion packs layer on genre-specific content on top.
- **Built-in FX chain** — Chorus, delay, reverb, and distortion are included, so patches can be polished entirely within the instrument.
- **SynthMaster Player** — A free player version lets producers load Synthmaster presets before committing to a full license.
