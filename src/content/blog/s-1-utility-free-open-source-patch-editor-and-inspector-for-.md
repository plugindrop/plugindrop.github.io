## What Is S-1 Utility?

S-1 Utility is a free, open-source desktop companion app for the Roland S-1 synthesizer, developed and publicly released by a community member. The Roland S-1 is notoriously limited in its MIDI CC capabilities and accepts no SysEx messages — which makes third-party editor support genuinely rare. S-1 Utility tackles that gap directly, offering a MIDI editor interface alongside a dedicated viewer for the S-1's native PRM patch backup files. Currently Windows-only, with Linux and macOS support listed as future goals.

## Key Features

- **MIDI Editor Interface** — Provides screen-based control over S-1 parameters that would otherwise require hands-on hardware navigation.
- **PRM File Viewer** — Reads and displays the S-1's native PRM backup files, letting you inspect patch data without the hardware physically connected.
- **Heuristic Sync System** — Because the S-1 takes no SysEx, the app uses a heuristic approach to stay accurate about the hardware's actual state, cross-referencing backed-up PRM files to keep the editor honest.
- **Open-Source Codebase** — Full source code is publicly available, meaning the community can contribute, fork, or audit the project at will.
- **Windows Support** — Fully functional on Windows now; Linux and macOS are on the developer's roadmap.
