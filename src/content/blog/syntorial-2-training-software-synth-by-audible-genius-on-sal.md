## What Is Syntorial 2?

Syntorial 2 is an interactive synthesizer training application developed by Audible Genius. Rather than watching passive video tutorials, it teaches synthesis through hands-on challenges — you hear a sound, then program a built-in software synth to match it by ear. The approach is closer to a musical instrument course than a typical DAW tutorial. It's designed to build genuine synthesis intuition, not just plugin familiarity.

---

## Key Features

- **Built-in software synthesizer** — lessons are taught using an integrated synth, so you're always working in context rather than reading theory in isolation.
- **Ear-training methodology** — the core loop is listen → recreate → refine, which builds muscle memory for recognizing synth parameters by sound.
- **Structured lesson curriculum** — covers fundamental synthesis topics progressively, from oscillators and filters to envelopes, LFOs, and beyond.
- **In-lesson challenges** — interactive exercises reinforce each concept immediately rather than leaving practice for later.
- **Preset recreation exercises** — puts knowledge to work by having you reverse-engineer real-world sounds.
