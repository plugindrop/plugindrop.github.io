## What Is XO?

XO is a drum machine and sample browser developed by XLN Audio, the company behind the Addictive Drums series. Rather than presenting samples in a traditional list or folder tree, XO uses a visual 2D map — sometimes described as a "galaxy" view — where drum sounds are plotted by sonic similarity using machine learning. The idea is to speed up sample browsing by letting producers explore by feel rather than by filename.

---

## Key Features

- **Visual Sample Map:** Drum sounds are displayed in a 2D scatter plot, organized by similarity — scroll and click to audition sounds spatially rather than alphabetically.
- **Built-in Sequencer:** An integrated step sequencer lets you build patterns directly inside the plugin without routing out to a DAW's MIDI editor.
- **Sample Import:** XO can index your own sample library alongside its included content, mapping your files into the same visual space.
- **Pattern Generator:** Randomization and variation tools help generate beat ideas quickly, useful for breaking out of creative loops.
- **Multiple Instrument Slots:** Load different drum sounds across kit pieces (kick, snare, hats, etc.) with per-slot processing controls.
- **Effects Processing:** Each channel includes basic processing options; check the product page for the current full effects list.
