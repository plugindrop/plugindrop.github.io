## Three Parallel Grain Engines Drive BEAM 2.0's Modular Effects Engine
<!-- role:product -->
BEAM 2.0 is built as a modular effects playground: any Lunacy effect can be loaded directly into its engine, turning the plugin into an expanding system rather than a fixed chain. Four modules anchor the 2.0 release. Grains is a real-time granular effect built for shimmering particle clouds, glitchy percussive grooves, and rhythmic soundscapes, running up to three parallel grain engines at once for speed and performance. Space is a convolution reverb carrying a curated set of impulse responses, including sound design credited to Benn Jordan and Venus Theory, covering textural spaces that transform audio into new soundscapes. Haze, new in this release, is a chorus and phase effect layered with algorithmic reverbs and dispersion for stereo width or feedback-driven resonance. Filter rounds out the set with new filter types and rolloff control added in 2.0. Every module doubles as a standalone plugin, and the 300+ global presets draw from sound designers including Venus Theory, J.Views, Dash Glitch, Databroth, and Alckemy Neuro.
