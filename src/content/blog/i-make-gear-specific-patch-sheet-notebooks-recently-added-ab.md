## How Patch Documentation Actually Works

For gear without deep patch memory — or none at all — the workflow is simple but easy to skip if you don't have the right tool for it: dial in a sound, write down the position of every relevant parameter (oscillator settings, filter cutoff and resonance, envelope times, LFO rate and depth, effects sends), and label it with a name or number you can find again later. A generic notebook forces you to redraw that structure every time. A gear-specific one has it pre-printed, so documenting a patch takes seconds instead of minutes — which matters a lot when you're mid-session and don't want to lose momentum chasing a sound you'll want again.
