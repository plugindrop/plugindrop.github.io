## What Is EastWest String Machine?

EastWest String Machine is a virtual instrument plugin from EastWest, the Los Angeles-based developer behind acclaimed libraries like Hollywood Strings and the Composer Cloud subscription. The plugin recreates the sound of vintage hardware string machines — the lush, chorus-drenched ensemble synths that defined pop, prog rock, and film scores throughout the 1970s and '80s. It's designed to deliver those period-specific textures without the hassle or cost of tracking down aging hardware.
