## What Is Arturia Memory V?

Memory V is Arturia's software instrument based on the Memorymoog, the classic polyphonic synthesizer released by Moog in 1982. The original hardware became legendary for its enormous, layered sound — thick pads, cinematic strings, and fat polyphonic leads that defined a generation of recordings. Arturia's plugin recreates that instrument's triple-oscillator architecture and analogue signal path, then extends it with modern modulation, performance, and effects features suited for contemporary production. It runs natively on both macOS and Windows.

- **Triple-oscillator architecture** — mirrors the original Memorymoog's per-voice oscillator structure for dense, harmonically rich textures
