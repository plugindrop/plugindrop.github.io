## What Is Rave Generation VA-1000?

Rave Generation VA-1000 is a downloadable virtual-analog synthesizer from Rave Generation. It uses subtractive synthesis and is built around an Ultrasaw oscillator, with features aimed at creating layered saw sounds, acid-style filter movement, chords, and tempo-synced patterns.

The instrument provides 16 voices of polyphony. Its feature set also includes onboard chorus, delay, and reverb, plus a separate VA-1000 FX version that processes external audio signals.

## Key Features

- **16-voice polyphony:** VA-1000 supports up to 16 simultaneous voices for chords and layered synth parts.

- **Ultrasaw oscillator:** Each oscillator can use up to nine detuned sawtooth waveforms, providing a route to wide stacked-saw textures.

- **JP-8000-style supersaw mode:** The synth includes a seven-voice supersaw mode for dense saw-based patches.

- **Multimode filter section:** Available filter options include Roland- and Moog-style 24 dB low-pass characteristics, plus high-pass, band-pass, notch, and peak modes.

- **Performance tools:** A tempo-synced arpeggiator and chord memory with 24 chord types support programmed rhythmic parts.

- **Built-in effects and FX plug-in:** Stereo chorus, delay, reverb, and ducking controls are included, alongside VA-1000 FX for processing external audio.

## Who Is It For?

- **Rave and trance producers:** The Ultrasaw and supersaw options are designed for detuned saw-based synth layers commonly used in these styles.

- **Techno and acid-focused workflows:** The TB-style acid mode and multiple filter types provide tools for filter-driven sequences.

- **Producers building chord patterns:** Chord memory and the tempo-synced arpeggiator can help create programmed harmonic parts inside the instrument.

- **DAW-based sound designers:** The included VA-1000 FX plug-in is intended for processing external audio, not only generating synth sounds.
