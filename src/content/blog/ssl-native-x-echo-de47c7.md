## Four Switchable Tape Heads Built on SSL's Plug-in Engine
<!-- role:product -->

X-Echo is a tape delay plugin from Solid State Logic, built on the company's SSL Plug-in Engine and bundled with SSL's cross-platform preset management and A/B-ing system, plus undo/redo support. Its design traces back to early hardware delay units from the 1960s, with the Echoplex tape echo named as a specific reference point. Rather than a single fixed delay line, the plugin offers four switchable tape heads for variation, alongside an interface with waveform visualization that shows how those heads interact with the signal.

Two controls drive the plugin's character: Wow & Flutter, which recreates tape-transport artifacts, and Saturation, which applies SSL-style distortion. A one-knob DIFFUSION control adds a newly designed reverb, and a built-in DE-ESSER is included specifically to tame the sibilant frequencies that tape echo effects tend to exaggerate. Delay timing can be locked to note values instantly, and FREEZE and KILL functions are provided for building risers and drops. A phase-shifting technique also converts mono input into a stereo signal. The plugin is distributed for AU, VST2, VST3, and AAX Native hosts on both Mac and Windows.

## Where Freeze, Kill, and Tempo Sync Fit
<!-- role:audience -->

- **Risers and drops** — FREEZE and KILL are built for constructing risers and drops in both studio recordings and live performances.
- **Mono-to-stereo widening** — a phase-shifting technique turns a mono input into a stereo signal without an external widening tool.
- **Tempo-synced repeats** — delay timing can be locked to note values with a single click for rhythmically consistent echoes.
