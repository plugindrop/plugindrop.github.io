## What you actually get

This allows for highly customizable crossover systems, making it ideal for complex mixing scenarios.

The plugin also includes a unique Dynamic Phase processing mode, which offers zero latency, no static phase changes, and no pre-ringing artifacts. This is especially useful for maintaining clarity in fast-moving audio signals. Additionally, it supports an excellent Linear Phase processing mode, which eliminates audible artifacts when quickly changing crossover frequencies.
