The LMC+ is their plugin recreation of the Listen Mic Compressor — a circuit originally embedded in the talkback section of the legendary SSL 4000 series console.

Engineers discovered decades ago that this compressor, never intended as a primary mixing tool, produced an extraordinarily aggressive, punchy sound when used on drum buses. SSL later refined and officially released it as the LMC+, adding features to make it more versatile while preserving the original's signature character.
